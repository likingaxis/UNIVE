- `local-only-files.json`: elenco dei file mantenuti localmente e rimossi dal tracciamento.
- `github-pages-before.json`, `environments-before.json`, `deployments-before.json`, `pulls-before.json`: inventario GitHub precedente all'intervento.

Per consultare la versione precedente in una cartella separata:

```sh
git clone ../UNIVE-backup-2026-10-17/UNIVE-before-cleanup.bundle ../UNIVE-prima-della-pulizia
```

Il bundle conserva i riferimenti originali. Un branch può essere recuperato dal relativo riferimento nel bundle senza modificare gli appunti correnti.
