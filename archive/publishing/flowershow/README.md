# Configurazione Flowershow archiviata

Questi file documentano il precedente sistema di pubblicazione, sospeso il 17 ottobre 2026.

- `package.json`: comandi e dipendenza del vecchio client di pubblicazione.
- `root/`: configurazione e CSS precedentemente nella radice della repository.

I percorsi dei vecchi comandi erano relativi alla radice della repository: non eseguirli da questa cartella. Un eventuale nuovo sito richiederà una configurazione dedicata. La precedente esclusione di `Percorso STUD2` è conservata nella configurazione archiviata.
