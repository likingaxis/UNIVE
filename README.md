## 💻 Come utilizzare gli appunti

### Opzione 1: Con Obsidian (Consigliato 🌟)

1. Scarica e installa [Obsidian](https://obsidian.md/).
2. Clona questo repository sul tuo computer:
   ```bash
   git clone https://github.com/likingaxis/UNIVE.git
   ```
3. Apri Obsidian, seleziona **"Open folder as vault"** e scegli la cartella del repository (o la cartella `content`).
4. Potrai sfruttare appieno la **Graph View**, i collegamenti bidirezionali `[[wikilink]]`, i diagrammi e il rendering KaTeX.

### Opzione 2: Consultazione diretta su GitHub

Puoi navigare direttamente tra le cartelle e i file Markdown tramite l'interfaccia web di GitHub, oppure consultare la pagina iniziale [`index.md`](./content/index.md).

## ✨ Caratteristiche del Vault

- 📐 **Supporto $\LaTeX$**: Tutte le formule matematiche sono scritte in KaTeX/LaTeX standard per una resa grafica perfetta.
- 🔗 **Interconnessione**: Note collegate tramite concetti chiave per facilitare il ripasso trasversale.
- 📝 **Schemi Unico/Short**: Riassunti compatti pensati specificamente per il ripasso pre-esame.
- 📊 **Esercizi Meccanici & Risolti**: Guide passo-passo per gli esercizi d'esame tipici.
