# 🎮 PACCHETTO SLIDE: DONNE, GAMING E INCLUSIONE
Università di Roma Tor Vergata · Corso di Gender & Inclusion

Questo pacchetto contiene tutti i formati pronti e completi della presentazione definitiva per l'esame.

---

## 📁 File Inclusi nel Pacchetto

1. **`donne-gaming-inclusione.pdf`** ⭐ *(CONSIGLIATO PER L'ESAME)*
   - È il formato ideale per proiettare in aula.
   - Si apre a schermo intero con `Ctrl + L` (o `F5` / modalità presentazione su qualsiasi lettore PDF o browser).
   - Risoluzione nitida al 100%, zero rischio che font o formattazioni saltino sul computer dell'università.

2. **`donne-gaming-inclusione.html`** 🌐 *(PRESENTAZIONE WEB INTERATTIVA)*
   - Basta fare doppio clic e si apre direttamente su Chrome, Edge, Safari o Firefox.
   - Supporta il tasto `F` per andare a schermo intero e le frecce direzionali per cambiare slide.
   - Include il visualizzatore Marp con animazioni e timer per il relatore (premi `P` per la modalità oratore).

3. **`donne-gaming-inclusione.pptx`** 📊 *(POWERPOINT)*
   - File PowerPoint standard pronto per essere proiettato con Microsoft PowerPoint o Google Slides.
   - Mantiene la resa visiva e cromatica esatta del progetto.

4. **`slide.001.png` ... `slide.009.png`** 🖼️ *(IMMAGINI SINGOLE)*
   - Tutte le 9 slide esportate in formato PNG ad alta definizione (16:9 widescreen).
   - Utili se volete inserirle in un documento Word, in una relazione o trascinarle in altre slide.

5. **`donne-gaming-inclusione.marp.md`** 📝 *(CODICE SORGENTE)*
   - Il codice sorgente Markdown con tutto il CSS e la struttura delle slide, modificabile in qualsiasi momento con Marp.

6. **Icone SVG e Asset Vettoriali** 🎨
   - Tutti gli asset grafici utilizzati (`icon-*.svg`, `avatar-*.svg`, `hud-controller.svg`).
