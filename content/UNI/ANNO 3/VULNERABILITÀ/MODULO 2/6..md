### Parte nuova
- INJECTION -> quando un'entità esterna riesce a far eseguire altri comandi o operazioni che inizialmente non erano previste sull'operazione web.
	- abbiamo injection diverse per codici diversi
		- php
		- sql
		- ecc...



- VARIE TIPOLOGIE
	- OS COMMAND INJECTION
		- ESEMPIO DI FUNZIONI
			- C/C++ -> system(); execvp(); ...
			- JAVA -> Runtime.exec(), ...
			- PERL -> system(), exec(), open(), ..
			- PYTHON -> ...
			- PHP -> ...
		Uso anche dei comandi propri del OS che sto bucando
		Se richiede l'input dell'utente posso avere una bella vulnerabilità
		- CONCATENARE COMANDI
			- `|`
			- `;`
			- `||`
			- `&&`
			- `&`
		- Nelle slide c'è un esempio con un'app web che dato un input esegue il ping di un IP che gli diamo noi
			- quindi esegue un comando bash
			- se io inserisco un comando "malevolo" posso sfruttarla
				- Tipo metto sia l'ip sia un comando mio `8.8.8.8 ; id` -> concatenazione di comandi
				- perché l'app farà `ping 8.8.8.8 ; id` -> SBEM PORCACCIODDIO
				- ECCO L'INJECTION
		- Le web app non sono programmate per avere input/output (non posso fare quindi sudo perché potrebbe chiedermi la password) e anche perché generalmente le web app girano con un id non privilegiato (`www-data`)
			- per risolvere il primo problema uso reverse shell
			- per risolvere il secondo faccio priviledge escalation dopo reverse shell
		
		- SOLUZIONI VISTA DIFENSIONE PER EVITARE DI VENIRE ATTACCATI
			- INPUT VALIDATION
				- fai una white list inserendo SOLO ciò che ti va bene che l'utente inserisca
					- nel caso di ping voglio
						- `MAX 3 numeri`, `.`, `MAX 3 numeri`, `.`,  `MAX 3 numeri`, `.`, `MAX 3 numeri`
				- la black list è più pericolosa perché se mi scordo qualcosa sono cazzi
			- PRINCIPIO DI PRIVILEGIO MINIMO
				- dai il minimo privilegio all'attaccante (non c'è il rischio di priviledge escalation qui????)
	
	- SQL INJECTIONS 
		- Ripasso di mysql 
			- il `LIMIT` servirà
			- la `UNION` è la base della SQL injection -> devono avere stesso tipo e stesso numero di colonne per fare la UNION (fa letteralmente l'unione)
			- i commenti sono importanti
			- tautologie sono importanti -> le usi con **OR 1=1**
			- COSA NON SCRITTA SULLE SLIDE -> **contraddizione** -> **AND 0=1**
