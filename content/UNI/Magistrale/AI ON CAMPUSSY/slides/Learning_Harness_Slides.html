Logical Clocks
##Core idea
• In distributed systems there is no single physical clock.
• Each process keeps a local counter C(i).
• When sending a message, it attaches its current C value.
##Happened-Before relation (→)
• Same process: if A occurs before B, then A → B.
• Message: if A is send(m) and B is receive(m), then A → B.
