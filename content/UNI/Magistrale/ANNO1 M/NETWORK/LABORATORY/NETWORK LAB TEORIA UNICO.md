- subnetting
	- processo di suddivisione di una rete IPv4 (32 bit) in sottoreti più piccole, spostando bit dalla parte _host_ alla parte _network_
	- con $h$ bit host si ottengono $2^h - 2$ indirizzi assegnabili ai dispositivi (esclusi Network ID con tutti `0` e Broadcast con tutti `1`)
- netmask
	- maschera a 32 bit con tutti `1` contigui per la parte network/subnet e tutti `0` per la parte host (espressa anche in CIDR, es. `/24`)
	- applicata in **AND bit a bit** all'indirizzo IP per ricavare il Network ID
	- il network ID sarebbe l'indirizzo che identifica quell'ip della network, si fa facendo AND bit a bit tra IP qualsiasi della rete di un host e quello della netmask
- subnet
	- sottoinsieme di host con lo stesso **Network ID** (`IP AND Netmask` identico) che formano un unico dominio di broadcast e comunicano tra loro direttamente a Livello 2, mentre richiedono un router (Livello 3) per raggiungere altre subnet.
- dominio di collisione
	- insieme di interfacce che comunicano con lo stesso mezzo trasmissivo, per cui se trasmettono contemporaneamente fanno avvenire una collisione, con un focus sul livello del TCP/IP (il secondo), se usi dei router avrai diversi collision domain perchè i router predispongono una porta per ogni singolo dispositivo
	- nel kathara sono le lettere del file `lab.conf`
